# DSE 化學平衡練習（Google Sites 可嵌入）

完整網頁檔是 `index.html`。Google Sites 不能直接貼上整個 JavaScript 應用，請先用 GitHub Pages 託管，再在 Sites 用網址嵌入。

## 開啟 GitHub Pages

1. 本 repo → Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` ，資料夾 `/ (root)`
4. 網址：https://sion2010.github.io/dse-chem-equilibrium/

請先把 `index.html` 上傳到 repo 根目錄（Add file → Upload files）。

## Google Sites

插入 → 嵌入 → 網址 → 貼上 Pages 網址 → 選整頁 → 拉高約 1100px → 發佈。
